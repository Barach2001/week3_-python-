# Week 3 Assignment: Conditions and Loops

## Files

- `grade_reporter.py`: Uses a for loop and conditional statements to assign grades, count passes and failures, and calculate the average score.
- `bug_hunt.py`: Fixes three bugs in a while-loop program so it correctly calculates the sum from 1 to 5.

## Bug Hunt Reflection

The hardest bug to find was the incorrect while-loop condition because it did not produce an error message; the program ran but stopped before adding 5. I knew something was wrong because the printed total did not match the required answer of 15. Checking which values the loop processed showed that the condition needed to allow the count to reach 5.
